# Ouroboros × Winners — Battle Plan (карта задач)

> Разбор 6 победителей Mantle Turing Test 2026. Что построили → как подали → что это даёт → **как мы прикручиваем, мутируем и усиливаем, чтобы у нас было круче**. Слоями: от самого жирного (max impact) к простому.
>
> Единая ось, к которой всё сводится: **«Автономный фонд, которому чейн не даёт сжульничать.»** LLM спорит — но решает детерминированный код, подпись проверяет контракт, а репутация растёт из реального PnL и её нельзя накрутить.

## LAYER 0 — Рамка и копирайт (почти бесплатно, делаем ПЕРВЫМ, max narrative/impact)

**Задача:** перестать прятать верифицируемость под «торговый терминал». Вывести ось в герой + подсветить, что LLM вне trust-пути.

- [ ] Герой: одна несомая строка — «Каждое решение подписано, риск-проверено и **чейн не даёт исполнить сделку, пока подпись не верифицируется**. Репутация — из реального PnL, накрутить нельзя.»
- [ ] Добавить фразу-щит (из OFT Sentinel + Conatus): «**Дебаты — лишь один вход. Решает воспроизводимый скор, риск-гейты в коде — LLM денег не касается.**» → прямой ответ на «галлюцинации / чёрный ящик».
- [ ] step 3 «Verify, don't trust» уже есть — оставить как plain-words вход в это (ссылка вниз к Verdict Explorer).

**Что маржим с нашим:** `judge.rs` уже детерминированный (LLM = фактор 5 из 15). Мы просто **впервые говорим об этом вслух**.
**Файлы:** `dashboard/src/App.tsx` (hero, steps-section), `App.css`.

## LAYER 1 — 🔑 Подписанное решение → on-chain принуждение + Verdict Explorer (САМОЕ ЖИРНОЕ, наш моат)

**Крадём у:** Stax (контракт ревертит без валидной подписи), Argus (executor пере-выводит триггеры), Conatus (вердикт-аттестация on-chain).

**Как они подали / что даёт:**
- Stax: «the contract refuses to move funds unless the AI's signed risk assessment passes verification» → доверие как механизм безопасности, а не фича.
- Argus: контракт сам считает триггер из оракула → даже свой агент не соврёт (trustless).
- Conatus: `{targetHash, findingsURI, riskScore, agentId}` в `AuditAttestation` → «records you can verify, not claims you trust». **На этом взяли Гран-при.**

**Как прикручиваем к нам:**
- [ ] Агент подписывает каждое торговое решение (EIP-712): `{pair, side, size, riskScore, expiry, nonce}`.
- [ ] Контракт-энфорсер на Mantle: перед свапом проверяет подпись + `riskScore ≤ userBound` + `!expired`, иначе **revert**. (куски есть: детерм. судья + on-chain адаптер `mantle-chain`).
- [ ] **Verdict Explorer**: апгрейд существующей карточки `Decision Journal` — каждая строка кликабельна → показывает входы + скор + `verdictHash` + tx на Mantlescan.

**Как мутируем/усиливаем (чтобы круче их):**
- Conatus верифицирует **аудит контракта**; мы — **живые торговые решения** + уже 4 500+ tx track record. Шире и «живее».
- Argus пере-выводит риск-триггер — добавляем то же: энфорсер **сам** пересчитывает риск из оракула+пула, чтобы даже наш агент не форсил плохую сделку.
- OFT PDR-хэш — добавляем `keccak256(inputs)==verdictHash` в каждую строку журнала → «пере-считай сам».

**Что маржим с нашим:** `turing-risk` + `judge.rs` дают скор; `mantle-chain` пишет on-chain; `Decision Journal` — готовый UI-сурфейс. Нужен слой подписи + verify-контракт.
**Файлы:** новый Solidity `DecisionVerifier.sol`; `swarm-engine`/`mantle-chain` (подпись+вызов); `App.tsx` карточка Decision Journal → Verdict Explorer.

## LAYER 2 — 🏅 Репутация, которую нельзя накрутить (surface it)

**Крадём у:** Conatus («the contract blocks the agent from rating itself»), Imara/Argus (ERC-8004 trust score).

**Что даёт:** «репутация» перестаёт быть словом — становится проверяемым числом с защитой от накрутки.

**Как прикручиваем:**
- [ ] Апгрейд карточки `On-Chain Activity` (уже есть Agent NFT `0xEb271…` + Mantlescan): заголовок → «ERC-8004 репутация — **растёт из реального PnL, само-рейтинг заблокирован**».
- [ ] Показать формулу: репутация = f(realized PnL, hit-rate, отклонённые сделки), с ссылкой на контракт.

**Как мутируем:** у Conatus репутация — из фидбэка потребителей; у нас — из **объективного on-chain PnL** (сильнее: не мнение, а результат). Это наш аргумент «объективнее, чем у Гран-чемпиона».
**Что маржим:** ERC-8004 identity уже задеплоена. Нужен честный источник скора + гейт `onlyOwner`/anti-self-rate.
**Файлы:** `turing-memory`/reputation-крейт; `App.tsx` карточка On-Chain Activity.

## LAYER 3 — 🔐 Co-pilot режим + bounded-autonomy session keys (снимает страх «автономка = страшно»)

**Крадём у:** CoQuant («human + AI co-pilot»), Imara (EIP-7702 session keys, revocable, лимиты), Stax (autopilot within hard bounds), Argus (pre-signed политики).

**Что даёт:** пользователь не боится дать агенту денег — ключ **scoped и отзывной**, а в co-pilot он подтверждает вход.

**Как прикручиваем:**
- [ ] Режим «предлагает → ты подтверждаешь» (уже в roadmap-копии героя «в паре с тобой») — сделать реальным: swarm формирует подписанное предложение → юзер апрувит.
- [ ] Wallet-connect с **session key** (ERC-4337 + EIP-7702): агент получает ключ с твоими лимитами, ты в любой момент отзываешь.

**Как мутируем:** большинство дали автономию ИЛИ co-pilot; мы даём **тумблер** между ними на одном подписанном примитиве из Layer 1 (то же подписанное решение — либо авто-исполняется, либо ждёт апрува).
**Что маржим:** тот же EIP-712 примитив, что и Layer 1 — переиспользуем, не строим второй раз.
**Файлы:** session-key контракт/логика; `SwarmChat.tsx` (approve-flow); roadmap-секция.

## LAYER 4 — ⚡ Консьюмер front door: gasless + social login (простота Stax)

**Крадём у:** Stax (Privy embedded wallet, Pimlico ERC-4337, email/passkey, PWA), Imara («no seed phrase, deploy < 2 min»).

**Что даёт:** Web2-юзер заходит без сид-фразы и газа → тот самый «UX-трек», который мы недобрали.

**Как прикручиваем:**
- [ ] Простой вход: email/passkey → embedded smart account (account abstraction), газ спонсируется.
- [ ] Плейн-словами чат уже star (`ai-console` первым в bento) — дожать онбординг «спроси словами».

**Как мутируем:** у них gasless — просто вход; у нас gasless вход **ведёт к подписанному-верифицируемому фонду** (Layer 1), а не к обычному свапу. Простота снаружи, моат внутри.
**Файлы:** wallet-провайдер (Privy/аналог), hero CTA.

## LAYER 5 — 🪙 $OUROBOROS как trust-primitive (stake/slash)

**Крадём у:** кластера Sentinel/REEF/agent-trust-arena (доверие к агенту как on-chain примитив).

**Что даёт:** токен перестаёт быть «ещё один коин» — становится **облигацией подотчётности**: агент ставит bond, слэш при пробое риск-лимитов.

**Как прикручиваем:**
- [ ] Дизайн: stake-bond агента; нарушение хард-лимита из Layer 1 = автоматический slash (событие уже есть — revert/kill-switch).
- [ ] Роадмап-секция уже упоминает $OUROBOROS — привязать механику к энфорсеру.

**Как мутируем:** у кластера «trust primitive» абстрактный; у нас слэш-триггер = **тот самый on-chain риск-энфорсер** из Layer 1 → механика уже подключена к реальному коду, а не декларация.
**Файлы:** токен/стейкинг контракт (позже), roadmap.

## LAYER 6 — 🎨 Вирусный/эстетический хук (опционально, низкий приоритет)

**Крадём у:** Cult of the Digital Oracle (PixiJS 60fps, кинематика, memorable hook).

**Урок:** Consumer-трек берут стилем + вовлечением ПОВЕРХ верифицируемого ядра. Стиля у нас уже много (живой фон/частицы) — сюда не вкладываемся, пока Layer 1–3 не готовы. Держим в уме один memorable момент (напр. визуализация «отказа» — рой отклоняет сделку зрелищно).

## Порядок исполнения (fat → simple)

1. **LAYER 0** — копирайт/рамка (часы, максимум нарратив-импакта на вложение). ← старт
2. **LAYER 1** — подпись→энфорс + Verdict Explorer (наш моат, реальный спринт).
3. **LAYER 2** — репутация без накрутки (surface, средне).
4. **LAYER 3** — co-pilot + session keys (переиспользует Layer 1).
5. **LAYER 4** — gasless/social онбординг.
6. **LAYER 5** — $OUROBOROS механика.
7. **LAYER 6** — вирусный хук (по остаточному принципу).

**Принцип:** каждый слой переиспользует подписанный примитив Layer 1 — не строим одно и то же дважды. Не копируем победителей — **берём выигравшую тему, в которой мы объективно глубже (живой PnL-track record + детерм. судья), и наконец подаём её как продукт.**
